# context-band

Segmento da faixa acima do prompt do Claude Code com o preenchimento da janela
de contexto, em barra preenchida e porcentagem, colorido como o `usage-band`. Avisa por
toast quando o contexto passa de 80% e de 90%. Combina com `model-band` e
`usage-band` em uma faixa única.

Instalar:

```
/plugin install context-band --marketplace nereumelo/claude-plugins
```
