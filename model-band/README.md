# model-band

Segmento da faixa acima do prompt do Claude Code que mostra o modelo em uso
(`claude-sonnet-5-5` vira `Sonnet 5.5`). Combina com `usage-band` e
`context-band` em uma faixa única: cada mod desenha o seu segmento e a ordem
fica fixa (modelo, contexto, uso), seja qual for a ordem de carga.
