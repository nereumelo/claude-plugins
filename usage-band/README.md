# usage-band

Segmento da faixa acima do prompt do Claude Code com o consumo dos limites da
assinatura: sessão (5 horas) e semanal (7 dias). Cada janela mostra uma barra,
a porcentagem e o tempo até o reset; a cor passa a amarelo a partir de 70% e a
vermelho a partir de 90%. Combina com `model-band` e `context-band` em uma
faixa única; sem dados de assinatura, mostra um traço.
