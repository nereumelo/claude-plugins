# usage-band

Faixa acima do prompt do Claude Code com o modelo em uso e o consumo dos
limites da assinatura: janela de sessão (5 horas) e janela semanal (7 dias).
Cada janela mostra uma barra, a porcentagem usada e o tempo até o reset. A cor
muda para amarelo a partir de 70% e vermelho a partir de 90%. Sem dados de
assinatura, mostra um traço no lugar.
